Mode: Operate. Scope: all five existing Streamlit views; presentation and navigation, not scoring or benchmark changes. User brief: make the frontend alive, remove emojis, install/use design skills.

## Direction contract
THESIS: Make a ranked inspection decision readable at a glance. Refuse marketing heroes and decorative feature grids.
OWN-WORLD: Daylit off-white workspace, deep petrol navigation, crisp teal selection, Public Sans with tabular numerals. Tight controls, flat table surfaces, one strong teal summary cell.
STORY: Select a branch, set inspection capacity, scan the queue, open an explained case. Evaluation and worker checks remain one navigation action away.
FIRST VIEWPORT: 264px sidebar; left-aligned title, visible synthetic-data badge, compact four-value summary, capacity control, then the ranked table alongside an actionable first-case preview.
FORM: Code-led original product UI. Installed frontend-design and Impeccable; engine unavailable, so direct documented fallback rather than an invented seed assignment. Restrained color strategy; no inherited visual identity beyond the TEPAT name.
FINISH: implemented and reviewed. DESIGN.md, the component sidecar, and DTCG export document the system. Browser evidence and finish verdict are in .impeccable/review/ (generated, gitignored). No shipping raster artwork; local font provenance and OFL license are included.

Signature interaction: open a queue case and preserve its selection in the case view. Motion: short focus/selection transitions only; respect reduced motion. No implied live BPJS connection.
